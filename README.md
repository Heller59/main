## 🤖 Mentor Chatbot

**.NET 9 (Blazor Server + ASP.NET Minimal API)**

A self-hosted, document-grounded AI chatbot platform. Upload a Word document, and
within minutes you have an embeddable chat widget that answers questions using
only the content of that document. Made up of three projects: `ChatBotAdmin`
(admin portal), `ChatBotServer` (public widget API), and `SampleApplication`
(embed demo).

**[→ Full README](./CHATBOT.md)**
